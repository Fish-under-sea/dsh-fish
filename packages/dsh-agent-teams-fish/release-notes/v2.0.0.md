# v2.0.0 · 并入 dsh-fish 聚合仓库

本版把 Fish fork 整体并入 [Fish-under-sea/dsh-fish](https://github.com/Fish-under-sea/dsh-fish)，作为工作区成员 `packages/dsh-agent-teams-fish` 与其它成员统一构建、统一版本、统一发布。包名保持 `@fish-under-sea/dsh-agent-teams-fish`，版本随聚合统一为 **2.0.0**。源码基线仍为上游 tag **v0.1.29**（commit `369c278`），本轮不同步新的上游代码。

## 变更

- **仓库并入**：`src/`、`lib/`、`assets/`、`scripts/`、`skills/`、`release-notes/`、`cordis.patch.yml`、`compatibility.json`、构建配置与 README/NOTICE/LICENSE 全部并入聚合仓库；原独立仓库不再单独演进。不带入 `.git`、`.github`、`node_modules`、`pnpm-lock.yaml` 等外部仓库残留。
- **身份字段**：`repository.directory` 指向 `packages/dsh-agent-teams-fish`，`homepage` / `bugs` 指向聚合仓库；新增聚合图标 `icon.png` 与 `icon` 字段。
- **插件清单元数据**：新增 `locale/zh.json`、`locale/en.json`（meta.title / meta.description），并在 `exports` 中导出；`exports` 同时补 `./src/*`，与其它成员一致。
- **发布清单**：`files` 覆盖 `lib`、`src`、`assets`、`locale`、`scripts`、`release-notes`、`cordis.patch.yml`、`compatibility.json`、`pnpm-workspace.yaml`（compatibility 策略清单，doctor 运行所需）、README、NOTICE、LICENSE 与 `icon.png`。
- **构建门禁适配**：`scripts/git-artifacts.mjs` 容忍包级 `pnpm-lock.yaml` 缺失（聚合仓库的锁文件在根目录），并重新生成 `lib/git-artifact-stamp.json`；独立检出时门禁行为不变。

## 不变

- 团队协作逻辑（花名册、任务 DAG、调度、质量门、信箱、面板）、配置字段与团队数据格式不变；状态目录仍是 `.agent-teams`，行 id 仍是 `agent-teams`。
- 宿主兼容声明不变：推荐宿主 `0.2.2-rc.1`，Node `>=24.9`；精确支持列表仍以 `compatibility.json` 为唯一事实源。
- 厂商美术体系与素材授权说明不变，见 `NOTICE.md`。
