# AgentTeams v0.1.22

Stable plugin release on npm `latest`, targeting the published DeepSeek Harness `0.2.0-rc.2` release.

- Switch the recommended host, exact development dependencies and dependency overrides to `0.2.0-rc.2`.
- Replace the previous predicted `0.2.0` peer target with the actual published RC; retain the seven earlier supported hosts.
- Keep prebuilt Git entries and pnpm 11 compatible dependency settings for desktop installation.
- Preserve source-candidate checks using explicit test fixtures, without declaring an unverified future GA version supported.

## Install

In Plugins → Add plugin, enter `@nanmicoder/dsh-agent-teams@0.1.22`. Use the npm official registry if a mirror has not synchronized the release. GitHub repository installation also includes the prebuilt entrypoints.

The host supplies its own core. For CLI installations, the exact host target is `@deepseek-ai/dsh@0.2.0-rc.2`; updating a global CLI does not update a desktop app's embedded core.

## Verification scope

Publication requires the eight-host runtime matrix and Ubuntu/Windows static checks for the same tarball. See [the migration record](../docs/harness-0.2.0-rc.2/README.md). Deterministic model fixtures and browser checks do not constitute real-provider or packaged Electron acceptance.
