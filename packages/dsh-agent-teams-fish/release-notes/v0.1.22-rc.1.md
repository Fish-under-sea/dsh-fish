# AgentTeams v0.1.22-rc.1

Preview release on npm `next`, preparing for the upcoming Harness desktop 0.2.0 release. The recommended published host remains `0.1.7-rc.2`.

- Ship prebuilt host and client entries in Git so desktop GitHub installation can activate without lifecycle build scripts.
- Move dependency overrides to pnpm-workspace.yaml for pnpm 10 and the desktop bundled pnpm 11.
- Add exact 0.2.0 peer compatibility, based on official Harness master commit `21638c56315ae6a2b552d6091945d3144c9af32e`. This is source preview evidence, not acceptance of the as-yet-unreleased desktop binary.
- Add checked-in build artifact integrity checks and an isolated source-host runtime verifier.

## Install

In the desktop Add Plugin field, enter `@nanmicoder/dsh-agent-teams@0.1.22-rc.1`. An npm website URL is not a package specification.

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.22-rc.1
```

Restart the active Harness profile and refresh its Web UI. This preview does not change npm latest.

## Validation

The pre-adaptation candidate passed ten real CLI scenarios with deterministic model fixtures on the pinned official source checkout, plus Web UI Git installation and activation under pnpm 11. The release pipeline requires Ubuntu and Windows static verification and all seven published host runtime targets against one immutable tarball before publishing.

See [the source audit and UI evidence](../docs/harness-0.2.0-pre-adaptation/README.md). Final official 0.2.0 packages and the packaged Electron application still require release-specific acceptance.
